# 🚀 ERP System Demo - Quick Start Guide

## 🏃‍♂️ Run Immediately

```bash

```

Then open your browser to `http://localhost:5000`

## 🛠️ Development Mode

```bash

```

This starts both Flask (backend) and React (frontend) with hot reloading.
